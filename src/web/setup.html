Set up the key box

This phone becomes the one that approves key actions. It makes a passkey and a device key that never leaves this phone. Both are needed for every approval.

If you reinstall the app or clear its data, the device key is gone and the only way back is recovery from the box's console.

The box sends its traffic only to the services it needs and refuses the rest. These limits do not stop an approved update that is malicious.
